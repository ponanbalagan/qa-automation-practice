# Selenium Java Practice

Browser automation practice using Selenium WebDriver, TestNG and Maven.

## Tech stack
- Java 21
- Selenium 4.50
- TestNG 7.12
- Maven 3.10

## Project structure
java-selenium/
├── src/test/java/com/qa/tests/   test classes
└── pom.xml                       dependencies and build settings

## Setup
1. Install JDK 21 or higher and Maven
2. Install Google Chrome
3. Check: mvn -version

## Run tests
mvn test
